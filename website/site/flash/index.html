Flash MeshPunk

Installs MeshPunk over USB from this page. Connect the device with a USB cable that carries data, then work through the four steps.

This browser cannot flash a device. Flashing needs Web Serial. Open this page in Chrome or another compatible Chromium browser on a computer, or use the download links below with another flasher.

1Your device

Builds are per device. A build for another device will not run correctly.

    Using bmorcelli's Launcher?
    
        
    A device that boots MeshPunk through the Launcher is updated from the Launcher, with the -launcher.bin file. Do not use the steps above on it: they replace the Launcher.
